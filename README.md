# Country Data Comparison: Tableau Dashboard and Story

## Overview
Interactive Tableau dashboards analysing economic, resource and public-health
indicators for 225 countries.

## Features
- Linked visualizations: map, bar charts, treemap, pie, scatter plot
- Parameters: Select Economic Indicator, Select Resources
- Calculated fields: Internet Penetration Rate (and others)
- Dashboard actions: filter, highlight, URL
- Interactive filters and navigation button to the Tableau Story

## Key insights
- A few countries dominate global GDP and population.
- HIV/AIDS deaths are concentrated in 3 countries (about 35% of world deaths).
- Extreme unemployment values appear in tiny economies, likely data-quality issues.
